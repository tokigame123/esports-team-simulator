# 最強のeスポーツチームを作ろう！シミュレーター

イベント用のボードゲーム進行シミュレーターです。

- サイコロによる順番決定
- チーム名の自由入力
- 創業資金100万ST
- 最大3人までの選手スカウト
- スカウト中チームの大きな表示
- 選手カード記載の獲得費用を使用
- 1ターン1マス固定移動
- ストリーマー、スポンサー、選手育成の選択移動
- 本編中に各チームの所持選手を確認
- スポンサー条件判定とターン収入
- 奇数週BO3試合
- 1回戦使用選手は2回戦使用不可、3回戦は全選手使用可能
- 対戦カードは1人ずつ秘密選択し、3,2,1後に同時公開
- 勝率、スポンサー数、ファン数、資金による得点計算
- 1〜6人プレイ
- 資料内から抽出したボード・カード画像を使用
- ブラウザのみで動作

`index.html` を開くと起動します。
